02 / Настройка

Четыре поля,
и шаблон готов.

Перед запуском замени только эти значения. Остальная структура уже подготовлена для Mihomo / Clash.

ПлейсхолдерГде используетсяПример
YOUR_PROXY_NAMEproxies[].name + группа VPNМой VPN
YOUR_SERVERproxies[].servervpn.example.com
YOUR_PASSWORDproxies[].passworduser:password
YOUR_SNIproxies[].snivpn.example.com
i
Важно: значения подставляются без лишних пробелов. После переименования прокси то же имя нужно оставить в группе 🌍 VPN.
Минимальный фрагмент
proxies:
  - name: "YOUR_PROXY_NAME"
    type: hysteria2
    server: YOUR_SERVER
    port: 4433
    password: "YOUR_PASSWORD"
    sni: YOUR_SNI
    skip-cert-verify: false
03 / Установка

Подключение
без лишних шагов.

Конфиг можно скачать напрямую или поставить готовым скриптом install.sh, который делает бэкап текущей версии.

01

Скачать YAML

Получить актуальную версию конфигурации напрямую из main.

curl -fsSL https://raw.githubusercontent.com/88venom14/vpn-config-hy2/main/config-hy2.yaml \ -o /path/to/config.yaml
02

install.sh

Скрипт создаёт каталог, качает конфиг и сохраняет прежнюю версию с меткой времени.

✓ бэкап .bak.дата✓ проверка curl✓ права 0644
03

Проверить и подключить

validate.sh проверяет плейсхолдеры, YAML и ссылки на rule-providers.

./validate.sh
Открыть актуальный YAML →

05 / Безопасность

Не публикуй рабочие
данные доступа.

В публичном репозитории оставляй только плейсхолдеры. Рабочий пароль Hysteria2, SNI и адрес сервера нужно подставлять отдельно. Помни: любой пользователь, у которого есть URL удалённого YAML, сможет скачать его содержимое.
