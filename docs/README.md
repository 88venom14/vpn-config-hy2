# Hysteria2 / Mihomo Config

## GitHub Pages

Страница `docs/index.html` рендерит `README.md` из репозитория и не требует сборки.

Контент загружается в браузере напрямую с `raw.githubusercontent.com`, поэтому
страница всегда показывает актуальное состояние README — отдельная копия текста
в репозитории не хранится и не может разойтись с оригиналом.

Включение Pages: **Settings → Pages → Source: Deploy from a branch →
branch `main`, folder `/docs`**.

## Как это работает

1. `fetch` забирает `README.md` по ветке `main`.
2. `marked` превращает Markdown в HTML.
3. `DOMPurify` чистит результат — README считается недоверенным вводом.
4. `highlight.js` подсвечивает код, кнопка копирования вешается на каждый блок.
5. Из заголовков `##`/`###` собирается оглавление с подсветкой активного раздела.
6. Относительные ссылки переписываются в абсолютные URL на GitHub.
7. С даты последнего коммита по файлу через GitHub API берётся «Обновлён».

Тёмная тема следует системной (`prefers-color-scheme`) и запоминает выбор в
`localStorage`.

Если файл не загрузился, страница показывает ошибку с прямыми ссылками на
репозиторий, а не пустой экран.

## Ограничения

* Рендеринг полностью клиентский, поэтому без JavaScript страница останется
  пустой — для статики нужен генератор вроде `pandoc`.
* README подтягивается по ветке `main`; на других ветках страница не работает.
* Запросы идут к GitHub без токена, поэтому действуют лимиты анонимного API.
  Для страницы с большим трафиком метаданные стоит кэшировать.
