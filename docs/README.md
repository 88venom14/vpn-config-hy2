# Hysteria2 / Mihomo Config — страница

Лендинг + живой рендер `README.md` из репозитория.

## Как это работает

Секция «04 / Документация» подтягивает `README.md` с ветки `main` в браузере:

1. `fetch` забирает файл с `raw.githubusercontent.com`
2. `marked` превращает Markdown в HTML
3. `DOMPurify` чистит результат — README считается недоверенным вводом
4. `highlight.js` подсвечивает код, на каждый блок вешается кнопка копирования
5. Относительные ссылки переписываются в абсолютные URL на GitHub
6. Бейджи собираются в один ряд, таблицы оборачиваются для горизонтального скролла
7. Дата последнего коммита по файлу берётся через GitHub API

Отдельная копия текста в репозитории не хранится, поэтому правки README появляются
на странице без пересборки.

Если файл не загрузился, показывается ошибка с прямой ссылкой на репозиторий,
а не пустой блок.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Разметка лендинга и контейнер для README |
| `styles.css` | Оформление, включая markdown-стили внутри карточки README |
| `script.js` | Загрузка README, рендеринг, копирование, тосты |
| `icon.png` | Исходник иконки 1000×1000, браузером не отдаётся |
| `favicon-32.png` | Фавикон для вкладки |
| `favicon-64.png` | Фавикон для Retina и тёмной темы |
| `apple-touch-icon.png` | Иконка «На экран Домой», 180×180 без альфы |
| `brand-mark-92.png` | Логотип в шапке, 1x (46 px) |
| `brand-mark-184.png` | Логотип в шапке, 2x (Retina) |
| `.nojekyll` | Отключает Jekyll |

Иконки генерируются из `icon.png` с сохранением прозрачности, кроме
`apple-touch-icon.png`: iOS игнорирует альфа-канал, поэтому она залита фоном
сайта (`#FBF0E6`).

Логотип в шапке (`brand-mark-*.png`) обрезан по альфа-каналу и показан прямо на
фоне страницы: у щита прозрачные углы, поэтому подложка под ним только
показывала бы белый ореол. Отображается 46 px, `srcset` отдаёт 2x для Retina.

## Ограничения

* Рендеринг клиентский, без JavaScript блок README останется пустым.
* README читается по ветке `main`; на других ветках страница не работает.
* Запросы идут к GitHub без токена и подчиняются лимитам анонимного API.
  При частом обновлении страницы нужен cache-buster — сейчас используется
  `cache: 'no-cache'`, что снимает кэш браузера, но не кэш CDN на 300 секунд.
